Sistem Informasi Kinerja Guru Wali

Deskripsi Proyek

Sistem Informasi Kinerja Guru Wali merupakan aplikasi berbasis website yang dirancang untuk membantu guru wali dalam mengelola, memantau, dan mendokumentasikan perkembangan akademik serta non-akademik peserta didik di SMPN 4 Batang Anai Kabupaten Padang Pariaman. Sistem ini dikembangkan untuk mendukung proses pencatatan dan pelaporan yang sebelumnya dilakukan secara manual agar menjadi lebih terstruktur dan mudah diakses.

Fitur Utama
  • Login dan manajemen akun pengguna.
  • Pengelolaan data peserta didik.
  • Pengelolaan nilai akademik formatif dan sumatif.
  • Pencatatan perkembangan non-akademik.
  • Rekapitulasi dan laporan perkembangan peserta didik.
  • Pengelolaan konsultasi guru wali.
Teknologi yang Digunakan
PHP MySQL Bootstrap CSS visual studio code
Peran dan Kontribusi

Berperan dalam analisis kebutuhan, perancangan sistem, pengembangan aplikasi berbasis PHP dan MySQL, pembuatan antarmuka, serta pengujian sistem.
